Практические задания по курсу "Статистический практикум". 
Содержание:
1. python_basics_library_oop.ipynb: 
   - Работа с кортежами и генераторами списков
   - Поворот матриц без использования циклов
   - Использование lambda-функций
   - Реализация системы управления библиотекой
2. numpy_matplotlib_practice.ipynb:
   - Построение графиков функций
   - Работа с gdown для загрузки данных
   - Визуализация гистограмм, столбчатых диаграмм, scatter plot
   - Вычисление корреляции и оценка пропущенных значений
3. statistical_simulation_tasks.ipynb:
   - Serial test и Permutation test
   - Сравнение генераторов случайных чисел
   - Генерация выборок из дискретных и непрерывных распределений
   - Генерация точек в круге и треугольнике
4. flight_delays_dashboard.ipynb:
   - Анализ задержек рейсов по часам, дням недели и месяцам
   - Исследование причин задержек
   - Рейтинг авиакомпаний по задержкам и отменам, рейтинг аэропортов по задержкам
   - Наиболее проблемные маршруты
5. KNN.ipynb:
   - Подбор гиперпараметров с помощью GridSearch
   - Сравнение KNN с логистической регрессией
   - Построение ROC-кривых 
   - Оценка качества модели на тестовой выборке
6. EDA_project.ipynb и Project.ipynb:
   Работа с Online Retail II Data Set (https://www.kaggle.com/datasets/tunguz/online-retail-ii), основные задачи:
   - При помощи иерархической кластеризации осуществить разделение клиентов по группам
   - Применить логистическую регрессию для предсказания возвращения клиента
   - Проанализировать временные закономерности в продажах
   - Выявить самые прибыльные рынки
   - Найти товары, которые часто покупают вместе
   - Составить список самых прибыльных и самых популярных товаров
   - При помощи построения кривой Парето выяснить какой процент покупателей формирует основную выручку
